# DTM — постановка следующих этапов

Прочитай этот файл, затем `docs/HANDOFF.md`, `README.md`, `docs/MAINTENANCE.md` и `src/series/fe/README.md`. Первым сообщением коротко скажи, что понял и с какого этапа начнёшь.

## Что уже есть (этап 0)

- `src/series/dtm/data/seasons.ts` — сезоны 2000…текущий год (возрождённая DTM), статья сезона, запоминание сезона; общий модуль `src/lib/yearSeasons.ts`.
- `#/dtm`, `#/dtm/:season` — страница-заготовка (`pages/DtmSeasonPage.tsx`, общий `src/components/UpcomingSeasonPage.tsx`), выбор сезона, подвал с источником, жёлто-чёрная тема (`src/styles/11-series.css`), карточка на стартовой странице.

## Источник — английская Википедия (проверено 09.11.2026)

| Что        | Где                                                                                             |
| ---------- | ----------------------------------------------------------------------------------------------- |
| Сезон      | `«2026 Deutsche Tourenwagen Masters»` (так же для всех лет с 2000)                              |
| Участники  | **Teams and drivers**                                                                           |
| Календарь  | **Race calendar** (в ранних сезонах — «Race calendar and winners»)                              |
| Результаты | **Results and standings** → Season summary (победители, поулы, быстрые круги по гонкам)         |
| Зачёты     | Drivers' championship, Teams' championship, Manufacturers' championship (с 2021 — также Rookie) |

На этапе обычно две гонки (суббота и воскресенье) — как сдвоенные этапы Formula E; разбирай колонки зачётов по заголовкам с `colspan`. Ранние сезоны (2000-е) устроены проще — фикстуры нужны минимум для 2000, 2021 и 2026.

## Этапы

1. **Сезон:** главная (ближайший этап, победители последних гонок, лидеры), календарь с двумя гонками на этапе, страница гонки, зачёты пилотов/команд/производителей, график мест.
2. **Участники и профили:** список пилотов и команд с номерами, профили пилота/команды/трассы, сравнение.
3. **Оформление:** эмблемы марок (общий `src/data/emblems.ts`: Audi, BMW, Mercedes, Porsche, Ferrari, Lamborghini, McLaren, Aston Martin, Ford…), фото, README и скриншоты.

## Переиспользовать (не копировать)

`src/api/wikipedia.ts`, `src/lib/wikitable.ts`, `src/lib/wikiStandings.ts`, `src/lib/wikiProfile.ts`, `src/components/PlacesChart.tsx` + `PlacesSection.tsx`, `src/components/Emblem.tsx`, `src/data/emblems.ts`. Образец устройства серии и сдвоенных гонок — `src/series/fe/`.

## Правила

Как в `docs/HANDOFF.md`: ничего не выдумывать, очки и места как у источника, источник и время под каждым блоком, фото только Commons с автором, классы CSS с приставкой `dtm-`, тесты на настоящих урезанных статьях, E2E с подменой Википедии, коммиты и пуш — только пользователь.
