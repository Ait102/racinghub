# Сравнение пилотов WEC — часть этапа 3

**Цель:** Проверенный самостоятельный блок сравнения двух пилотов перед следующими частями этапа 3. Пользователь поручил выбрать порядок с учётом лимита; сначала сравнение, затем оценка остатка. Коммиты и пуш делает пользователь.

**Решение:** `#/wec/:season/compare?a=…&b=…`, два выбора из Entries выбранного сезона. Старые пилоты из ссылки остаются выбранными при смене сезона. Профиль каждого пилота загружается существующим `getProfile`, без обхода сезонов. Используются `profileStats`, `DataState`, `NameFlag`, `PageHeader` и обычные таблицы. Новых зависимостей и импортов из F1 нет.

**Что видно:** две карточки со ссылками на профили, количеством сезонов WEC, титулами завершённых сезонов, победами и подиумами в классе Ле-Мана; ниже общая таблица сезонов с командами, классами, местом и очками каждого пилота. Несколько строк одного сезона сохраняются. Нет строки — «нет у источника», не утверждение об отсутствии выступлений. Нет колонки — «—». Очки не суммируются. Преимущество по очкам и местам разных классов не выделяется. Источник и время есть у каждой карточки и под общей таблицей.

## Проверки и порядок

- [x] `domain/compare.test.ts`: реальные профили Буэми/Кобаяси; союз сезонов, суперсезоны, несколько классов/команд в одном сезоне, дробные очки и `*`, отсутствующие колонки/таблицы. RED → GREEN для `compareSeasons(a, b)`.
- [x] Страница, маршрут, меню, ссылка из профиля и списка; доступные подписи двух выборов, обмен сторон, сохранение в URL, отсутствие загрузки при недопустимом или одинаковом выборе. Ошибки сторон независимы; не показывать старую пару после изменения выбора.
- [x] E2E: выбор/обмен, ссылка из профиля, прямая ссылка и смена сезона, одинаковый/неизвестный/недопустимый пилот, ошибка и повтор, пустая история, мобильная ширина и клавиатура. Живой контракт на вторую статью и данные сравнения, визуальный маршрут.
- [x] Unit, типы, lint/Prettier, полный E2E, контракт, визуальные снимки, сборка, production audit. Обновить README, HANDOFF, TESTING, MAINTENANCE и WEC README. Не запускать два набора Playwright одновременно: они используют одну папку артефактов.

Остальные части этапа 3 (график мест, избранное, эмблемы и фото машин) в этот блок не входят.

## Результат

Реализация завершена без коммитов и пуша. Unit 142/142, E2E 47/47, типы и production-сборка проходят, lint/Prettier без замечаний, production audit 0. Визуальный прогон с обновлением эталонов 1/1: 22 страницы на двух ширинах. Отдельное повторное сравнение с новыми эталонами не запускалось.

Независимая проверка не нашла важных ошибок логики. Устранены неиспользуемый импорт и неверный индекс ячейки в E2E; проверка отказа профиля теперь ждёт ошибку именно статьи, устраняя гонку со сбоем блока сезона. Последний полный живой контракт 9/15: 5/6 F1 и 4/9 WEC; F1 не публикует протокол 2026/19, пять проверок Википедии получили 429. Новая проверка сравнения на живом источнике из-за 429 не подтверждена. Частые повторы не выполнялись. Ограничения записаны в TESTING и HANDOFF.
