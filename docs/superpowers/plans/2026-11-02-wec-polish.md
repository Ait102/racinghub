# WEC: оформление, источники и профили

> **For agentic workers:** Use superpowers:executing-plans for implementation. Steps use checkbox syntax. Коммиты и push выполняет только пользователь.

**Goal:** Выполнить список из 12 исправлений WEC и обновить README для обеих серий.

**Architecture:** Сохранить React, существующие загрузчики и синюю тему WEC. Главная использует визуальные приёмы F1; общий код не импортирует F1. Новые сведения читаются из Википедии, фотографии только из Commons с атрибуцией. Независимые части проверяются отдельно и вместе.

**Tech Stack:** React 18, TypeScript, CSS, Vitest, Playwright. Без новых зависимостей.

**Spec:** Список пользователя в текущем чате от 02.11.2026. Пользователь ранее передал выбор решений ИИ («делай как считаешь правильно»). Основа дизайна — действующая F1, синяя палитра WEC.

## Global Constraints

- Коммиты, push и публикацию выполняет только пользователь.
- Очки и места не пересчитываются; неизвестные значения не выдумываются.
- Источники, лицензии и время загрузки сохраняются. WEC/общий код не импортируют F1.
- Существующее избранное F1 сохраняется. Новые CSS-классы WEC имеют приставку wec-.

## Review Focus

- Фото не является логотипом/схемой, свободная лицензия подтверждена Commons; нет фото — понятное отсутствие.
- Несколько моделей и участников команды не теряются при объединении заявки.
- Историческая конфигурация трассы соответствует году, неизвестная не подменяется современной.
- График не рисует место 0 и не соединяет пропуски; подписи читаемы на телефоне.
- Смена серии и страницы источников сохраняет правильные меню, цвет и сезон.
