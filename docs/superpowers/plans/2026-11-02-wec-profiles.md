# WEC profiles implementation plan

**Goal:** Выполнить этап 2 из `docs/HANDOFF.md`: профили и списки участников WEC.

**Architecture:** Существующий клиент Википедии загружает одну статью профиля. Общий разбор `wikitable` читает строки по заголовкам. Профиль команды показывает только доступные таблицы WEC из её статьи и строку выбранного сезона из уже загруженных зачётов; загрузки всех сезонов нет. Профиль трассы получает историю из статьи гонки и фото из статьи трассы.

**Tech Stack:** React, TypeScript, Vitest, Playwright; без новых зависимостей.

**Spec:** `docs/HANDOFF.md`, этап 2. Пользователь поручил реализацию в текущем чате; коммиты и пуш делает пользователь.

## Constraints and review focus

- Очки и места остаются текстом источника; нет данных — «—».
- Статистика класса использует только явно опубликованные места в классе. Общие места WEC нельзя считать победами в классе.
- Титулы учитываются только для прошедших сезонов; несколько строк одной машины или сезона не удваивают счётчики.
- Статьи без таблиц и недопустимые адреса получают понятное сообщение; ссылки с диакритикой и косой чертой кодируются.
- При смене профиля или сезона старые данные не отображаются; кэш профилей ограничен по времени, поскольку карьера продолжается.
- Ссылки внутри карточек календаря не вкладываются друг в друга. Общий код и WEC не импортируют F1.

## Проверка реализации

План реализован в исходной рабочей копии по поручению пользователя, без коммитов и пуша. Entries читается отдельным запросом: список участников не зависит от зачётов. Классные победы WEC не считаются по общим местам; явно опубликованные места класса Ле-Мана используются отдельно. История команд не достраивается отсутствующими сезонами.

Независимая проверка кода: исправлен подтверждённый случай отсутствия колонки итогового места (unit RED → GREEN, вместо 0 титулов показывается «—»). Добавлен флаг из заявки, когда пилота нет в зачёте (E2E с точным названием статьи Tom Gamble (racing driver)). Других важных дефектов проверка не нашла.

Фактические результаты: unit 139/139, E2E 41/41, типы/сборка/lint проходят, production audit 0. Живой контракт WEC 8/8, общий 13/14 из-за пустого протокола F1 2026/19 у Jolpica; подтверждено отдельным запросом. Окончательная визуальная проверка и актуальные результаты — в `docs/TESTING.md`.
