# WEC — FIA World Endurance Championship

Раздел гонок на выносливость: сезоны с 2012 года, данные из английской Википедии (CC BY-SA 4.0).

## Почему Википедия

Бесплатного стабильного API для WEC нет (проверено в ноябре 2026):

| Источник                      | Почему не подходит                                                              |
| ----------------------------- | ------------------------------------------------------------------------------- |
| Al Kamel, fiawec.com, fia.com | официальные, но без CORS и без API — браузер их не прочитает                    |
| OpenWEC (api.openwec.com)     | версия 0.1: дубли строк, несколько ID у одного пилота, нет стран, дат и зачётов |
| TheSportsDB                   | бесплатно — 15 событий без результатов                                          |

В Википедии есть всё за все сезоны, и статьи устроены одинаково.

## Как устроено

```
wec/
├─ api/wikipedia.ts     запросы к MediaWiki parse API: у сезона — 2 раздела, у гонки — статья целиком
├─ data/seasons.ts      список сезонов (2018–19 и 2019–20 — «суперсезоны» через два года)
├─ domain/types.ts      модель: этап, победители классов, протокол, квалификация, тренировки, зачёты
├─ domain/parse.ts      разбор таблиц: колонки ищутся по названиям, классы и зачёты — из самих таблиц
├─ domain/status.ts     статус этапа: «Завершён» только при опубликованном результате
├─ hooks/data.ts        хуки загрузки поверх общего useResource
├─ components/          флаги из Википедии, значки классов, выбор сезона
├─ pages/               обзор, календарь, этап, зачёты
├─ contract/            живая проверка Википедии (npm run test:contract)
└─ __fixtures__/        урезанные настоящие статьи 2012, 2019–20 и 2026 для тестов
```

Общий разбор таблиц Википедии (объединённые ячейки, флаги, ссылки, цвета) — в `src/lib/wikitable.ts`.

## Правила

- Очки и места — как у источника, без пересчёта. Место в классе — порядок строк источника.
- Нет данных — «—» или «нет у источника», не выдуманные значения.
- Под каждым блоком данных — ссылка на статью и время загрузки.
- WEC не импортирует ничего из `series/f1` (проверяет ESLint). Общее — в `src/`.

## Этапы

1. ✅ Обзор, календарь, протоколы по классам, квалификация, тренировки, все зачёты.
2. ✅ Профили пилотов, команд и трасс (по ссылкам на статьи Википедии), заявочные списки участников.
3. ✅ Сравнение пилотов, график мест по этапам, избранное, эмблемы производителей и фото машин.

## Профили и участники (этап 2)

- `domain/profiles.ts` читает только разделы результатов WEC, Ле-Мана или Winners. Заголовки и строки сохраняются как у источника, объединённые ячейки разворачивает общий `wikitable`. Очки не складываются. Другие чемпионаты в статистику не попадают.
- У пилота — история WEC, Ле-Ман, фото Commons, флаг и строка зачёта выбранного сезона. Счётчики: уникальные сезоны WEC, титулы завершённых сезонов, победы и подиумы **в классе Ле-Мана** (колонка Class Pos.). Победы WEC не считаются: статья не всегда отделяет места в классе от общих мест.
- У команды или производителя — строка выбранного сезона и доступные таблицы результатов из собственной статьи. Несколько машин сохраняются отдельными строками. Например, в статье AF Corse история WEC неполная; остальные сезоны не достраиваются.
- У трассы — фото из статьи трассы (`?circuit=…`) и Winners из статьи гонки, ссылка на которую хранится в `WecRound.eventArticle`. Если классов в таблице нет, показываются общие победители с пояснением. Не каждая статья содержит Winners.
- `domain/participants.ts` разбирает раздел Entries статьи сезона: команды, все строки экипажей, флаги, классы. Списки доступны до первой гонки; повторяющиеся участники объединяются по статье, классы сохраняются. Поиск и сортировка используют общий `SortableTable`.
- `getProfile` загружает одну статью и следует редиректам; её кэш — 10 минут, даже при открытии из старого сезона. Карьера продолжает меняться. Зачёт выбранного сезона загружается отдельно существующим `getSeason`; все сезоны карьеры не запрашиваются.
- Неизвестная статья и недопустимый адрес получают отдельные сообщения. Названия статей кодируются в URL, включая диакритику и `/`. Фото — только Commons, с автором и лицензией; отсутствие фото не создаёт ошибки страницы.

Фикстуры профилей и заявок — настоящие таблицы со ссылками на источник и датой получения в HTML-комментарии. Обновление: `node scripts/fetch-wec-profiles.mjs` и Prettier; аргумент `season` обновляет только заявки. Запросы скрипта подписаны User-Agent проекта.

## Сравнение пилотов (этап 3, часть 1)

Маршрут `compare?a=…&b=…`, страница `pages/WecComparePage.tsx`. Пилоты выбираются из Entries выбранного сезона; прямые ссылки поддерживают старых пилотов и сохраняют выбор при смене сезона. Есть обмен сторон, ссылки из профиля и списка, пункт меню. Недопустимые и одинаковые названия не загружаются; редиректы на одного пилота также распознаются.

`domain/compare.ts` сопоставляет только WEC-таблицы двух профилей по сезону. Сохраняются все строки команды/класса, исходные места, дробные очки и звёздочки. Нет строки — «нет у источника», нет значения — «—»; отсутствие выступлений не предполагается. Нет сумм очков и выделения победителя сравнения по результатам разных классов. Статистика использует существующий `profileStats`: титулы прошлых сезонов, победы/подиумы только в явно указанном классе Ле-Мана.

Источники и время указаны под обеими карточками и общей таблицей. Каждая сторона использует существующий `getProfile` и его кэш, без запросов по всем сезонам; заявка сезона загружается отдельно. Ошибка одной статьи не скрывает другую карточку, но общая таблица строится только после загрузки обеих. При изменении выбора прежняя пара не показывается. Фото и новые источники для сравнения не загружаются.

## График мест (этап 3, часть 2)

На странице зачётов под таблицей — график «Места по этапам» для выбранного зачёта (Топ-5 или Топ-10 строк). `domain/places.ts` берёт места из клеток той же таблицы: только числа, «Ret», «NC», «DSQ» и пустые клетки дают разрыв линии и видны в подсказке. У производителя — линия на каждую машину. Пилоты одного экипажа с одинаковыми результатами показаны одной линией со всеми именами. Это место в гонке, а не положение в зачёте после этапа: очков после каждого этапа источник не публикует, пересчёта нет. Новых запросов нет. Компонент `components/PlacesChart.tsx` повторяет устройство графика F1 (наведение, стрелки), но без импорта из `series/f1`.

## Избранное, эмблемы и фото машин (этап 3, часть 3)

- **Избранное.** Общее хранилище — `src/hooks/useFavorites.ts` (`createFavorites`): у каждой серии свой ключ и своё событие. F1 по-прежнему хранит `racinghub:f1:favorites` с ID Jolpica; WEC — `racinghub:wec:favorites` (`hooks/favorites.ts`), ID — названия статей, проверка — `validArticle` (пробелы, диакритика и `/` допустимы). Звёздочка — в профиле пилота и команды; избранные выделены в списках «Пилоты»/«Команды» и в зачётах, на обзоре сезона — блок «Избранное» с местом и очками из первого найденного зачёта, как у источника. Кнопка — общий `src/components/FavButton.tsx`.
- **Эмблемы производителей.** `data/emblems.ts`: файл в `public/logos/`, источник, лицензия, правообладатель, `tone` и цвет круга; общий компонент `src/components/Emblem.tsx` (им же пользуется F1). Эмблема ставится, если название начинается с производителя («Toyota Gazoo Racing», «Mercedes-AMG Team …»); иначе — по маркам машин команды из заявки сезона, если все они одной марки (The Bend Manthey — Porsche, Garage 59 — McLaren). У команды с машинами разных марок эмблемы нет. Показывается в зачётах производителей и команд, в списке команд, на обзоре и в шапке профиля команды. Для Porsche нашлась только несвободная PNG-версия герба.
- **Фото машин.** В профиле команды — «Машины сезона»: модели берутся из колонки Car заявки сезона (`Participant.cars`), свободное фото с Commons выбирается по соответствию модели и варианту в статье. Автор и лицензия подписаны. На фото может быть машина другой команды или года той же модели; дорожная версия не подставляется вместо гоночной. Неподтверждённое фото отсутствует с пояснением.

## Обновление WEC: главная, профили, карты и график (02.11.2026)

- «Обзор» в меню заменён на «Главная». На главной есть прогресс сезона, значки Hypercar/LMGT3, ближайший этап, отдельные карточки зачётов с названиями источника и победители последней гонки. Под карточками календаря больше нет отдельных ссылок: трасса и победители открываются со страницы этапа («О трассе и победители»).
- `pages/WecSourcesPage.tsx`, маршрут `#/wec/:season/about`: данные, ограничения, фото, схемы, эмблемы, лицензии и правообладатели. Footer WEC указывает Википедию; карточки и страницы сохраняют конкретные ссылки и время получения.
- Пилот: `facts`, `biography`, `photoFiles` из той же статьи, без дополнительного обхода сезонов. Основные сведения и краткая биография выводятся отдельным блоком с источником; текст биографии остаётся на языке статьи. Скрытые даты и результаты других чемпионатов не попадают в факты WEC.
- Фото: общий загрузчик использует очередь и повтор существующего HTTP-клиента. Берётся свободный файл с Commons: JPEG, либо PNG/WebP с подтверждённым фотографическим содержимым. Учитываются фото инфобокса, а не только `pageimages`; логотипы и схемы отсекаются. Ошибка или отсутствие фото не скрывают остальные данные профиля.
- Галерея команды объединяет все её строки заявки по запрошенному и каноническому названиям статьи, сохраняет разные модели, даже если они ссылаются на одну статью. Выбор изображения учитывает название и вариант модели в подписи, имени файла или разделе; фото дорожной Ferrari 296 не подменяет 296 GT3 Evo. Фото другой команды или года допустимо как фото той же модели с соответствующим пояснением.
- `components/WecCircuitPanel.tsx` и `data/circuits.ts`: описание, длина, повороты, направление и схема на этапе и в профиле трассы. Общие контуры вынесены в `src/data/circuits`, отображение — в `src/components/CircuitMap.tsx`; старые экспорты F1 совместимы. WEC отдельно выбирает конфигурации Бахрейна, Фудзи и Имолы, не опираясь на годы проведения F1.
- Ле-Ман и современный Себринг используют отдельную геометрию © OpenStreetMap contributors через track-atlas, ODbL 1.0. Воспроизведение: `node scripts/build-wec-circuits.mjs`. Под схемами есть источники и лицензии. Снимок проверенных WEC-конфигураций ограничен 2026 годом; более старые неподтверждённые схемы Ле-Мана и вариант WEC Нюрбургринга не подменяются похожими контурами.
- График: отдельные машины производителей и команд больше не объединяются по совпадению результатов. Пилоты группируются только при совпадении опубликованных команды, места, очков и всех результатов. Ноль и некорректные числа не считаются местом. Подробности этапа находятся под SVG, доступны касанием, стрелками, Home/End и Escape; длинные имена и подписи помещаются на телефоне.
- Peugeot показывается без инверсии исходной белой эмблемы на чёрном фоне. Лицензия и источник файла сохранены.
- Классы Hypercar и LMGT3 обозначаются прозрачным знаком в цветной рамке из двух строк — «HYPER / CAR» и «LM / GT3», как на официальных табличках классов; остальные классы прошлых лет — цветной плашкой с названием. Знак стоит в карточках главной, в календаре, перед названием каждого зачёта, в колонке классов списков пилотов и команд. Полное название класса остаётся доступным для экранных читалок.
- График мест: десять хорошо различимых цветов; наведение или нажатие на имя в легенде выделяет одну линию, остальные бледнеют. Пропуск этапа соединяется бледным пунктиром, а сход, NC, DSQ — крестик в отдельной нижней строке «сход», без выдуманного места.
- Профиль пилота: полное имя из ячейки «Born» — отдельный факт, дата и место рождения разделены запятой; транскрипция произношения из биографии убрана. В шапке профиля без свободного фото просто нет фото, без поясняющей надписи. На главной — одна строка источника на всю страницу (все блоки из одной статьи сезона).

Внутренние правила остаются прежними: очки и места не пересчитываются, недостающие данные не достраиваются. Точные результаты проверок текущего обновления — в `docs/TESTING.md`.
